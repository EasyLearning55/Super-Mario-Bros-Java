Mario Nes and Snes Versions in Java for PC , Mac and Linux

60 FPS Mario = 60 FPS , NES Graphics
Mario Snes Graphics = 30 FPS , SNES Graphics

Sound Fixed Mario NES Jar and Source Code = 60 FPS , NES Graphics
Sound Fixed Mario SNES Jar and Source Code = 30 FPS , SNES Graphics

When you first Launch the Game it will as you for settings
once you click "OK" setting will be saved in "Setting.txt"

next time you Launch the game it will automatically load settings from previously saved setting

if you dont want to see the settings windows again and directly launch the game you can check the box "Skip this next time"
then game will launch directly without setting window

if you want to bring back setting window , delete the file Setting.txt and lauch the game again
